    • Public observer: Private. Each pool has one fixed amount and no in-pool transfers, so every withdrawal spends exactly one deposit.

    • Privileged insider: Private. The pools cannot be paused, upgraded or made to reveal anything.
    • Future adversary: At risk. Whoever breaks elliptic-curve cryptography can test whether a given deposit could fund a withdrawal, since commitments use a Pedersen hash on an elliptic curve.

  4. 4Umbra CashPrivacy assessment
    • Public observer: Private. Each payment goes to a fresh stealth address, and only the recipient's viewing key shows whose it is.

    • Public observer: Private. A zero-knowledge proof hides which approved notes a withdrawal or transfer spends, and a transfer publishes only encrypted notes.

    • Future adversary: Exposed. Every registered account's viewing public key sits in the Keystore, so whoever breaks elliptic-curve cryptography decrypts every note ever sent to it from the chain.
